# Site da Vera

Homenagem de Dia das Maes para Vera, com carta do William, video especial da Tiffany e albuns de memorias da familia.

## Estrutura

- `public/photos/`: fotos usadas nos albuns e imagens de capa.
- `public/videos/`: videos otimizados para web usados pelo site.
- `public/audio/`: trilhas gratuitas dos albuns e arquivo de licencas.
- `source-media/videos-originals/`: videos originais preservados fora do build.
- `src/media.generated.ts`: lista gerada com os albuns, fotos, capas, videos e musicas.

## Comandos

- `npm run dev`: abre o servidor local.
- `npm run build`: compila a versao final em `dist/`.

## Publicacao

O projeto esta configurado para GitHub Pages no repositorio `William-Merces/site-vera`.
Ao enviar commits para a branch `main`, o GitHub Actions compila o Vite e publica o conteudo de `dist/`.

Endereco esperado:

`https://william-merces.github.io/site-vera/`
